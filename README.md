# trend-vault-site

The public website and privacy policy for Trend Vault — used as the company
website and privacy policy URL for the Pinterest developer app.

| Page | URL |
|---|---|
| Home | https://inajaf.github.io/trend-vault-site/ |
| Privacy policy | https://inajaf.github.io/trend-vault-site/privacy.html |

Plain HTML and CSS, no build step. Served by GitHub Pages from the `main` branch.

## Why this repository is separate

The extension repository is private and holds commercial strategy. This one is
public because the privacy policy has to be reachable by anyone reviewing the
app, and because links from published content should point at a domain we control
rather than at a marketplace product page.
